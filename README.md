# FirstKeyboard

-ios의 영문 쿼티 + 롱터치 특수문자 키보드 
키보드버튼의 롱 터치시 특수 문자 및 숫자가 나오도록 작성

주 키보드 파일은 KeyboardViewController.swift

TextString 과 KeyboardButton을 키보드 타겟 앱이 아닌 호스트앱에 작성하여 공유하도록 작성
추후 호스트앱에서 텍스트에 대한 변경지원 예정
